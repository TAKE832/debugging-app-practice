## 概要

COATHTECH 教材 10-4「デバッグ ハンズオン演習」で作成した成果物です。
（既存のコードのバグの原因を Log や dd() を使って見つける方法の練習を行いました。また、Middleware にログを仕込んで、HTTPライフサイクルの流れを可視化する方法も学びました。）

## 使用技術

- PHP 8.x
- Laravel 10.x
- デバッグツール（'dd()', 'dump()', 'Log' ファサード）

## 学んだこと

- Middlewareを各ルートに仕込むことによって、コントローラー実行前と、実行後にログを出すことができると、アプリケーションのバグの発見やセキュリティ強化に繋がるため、非常に便利だと思った。
- Webで動作を正常にしているか確認する際、バグがあったら表示されるエラーメッセージは、バグの原因や動作のログを表示してくれるため、バグの早期解決に繋がることが分かった。これからの学習でも、エラー内容をしっかりと読み解き、早期修正につなげられるよう活用していきたい。
- practice で作成したログの文章は簡易的なものだった。しかし、sample ではユーザーからのリクエスト内容や、どの動作を行っているかが分かりやすくなるタイトルの付け方をしていた。これは、ログの可読性も高まり、どのユーザーがアクセスしているかが分かりやすいため、セキュリティ強化につながるため、これからログを仕込む際、参考にしていきたい。

## 詰まったポイントと解決方法

- コントローラーにログを仕込むことはできたのだが、どのようにMiddlewareにログを移動させるのかが分からなかった。そこで、過去の教材を探してみたり、Webで調べたりすることで、Middlewareにログを仕込む方法を知り、実装することができた。

## 動作確認

- （http://localhost/users/create） にアクセスし、フォームを送信してバグの内容を読み解き、デバッグを行った後、正常な動作をするか確認した。また、ログを仕込み、動作の際にログが送られてくるようになっていることも確認した。
